# Data

| Folder | Contents | Label |
|---|---|---|
| `public/` | `small_business_cashflow.csv` provided with the hackathon challenge (USD, 1,600 monthly snapshots) | Provided dataset - benchmark only |
| `synthetic/` | Training panel from `scripts/generate_synthetic.py` (210 fictional SMEs, MUR) | **Synthetic** |
| `demo/` | `coastal_petty_cash_sep2026.csv`, a deliberately messy import file for the demo | **Synthetic** |
| `reference/` | Hand-written category keyword lexicon (training text for the category suggester) | Hand-written |
| `eval/` | Hand-written category test set, never used for training | Hand-written |

Nothing here is real business or personal data. See `docs/DATA_DICTIONARY.md`.
