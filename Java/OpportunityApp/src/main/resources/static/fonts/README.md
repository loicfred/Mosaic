# Fonts

Served from here so the demo needs no internet (NFR-7). Both are variable fonts, Latin subset, downloaded
2026-09-24 from Fontsource (`cdn.jsdelivr.net/fontsource/fonts/...`). Licence: SIL Open Font License 1.1.

- `bricolage-grotesque-latin-wght-normal.woff2` — Bricolage Grotesque (Ateliertriay): page questions and section headings.
- `atkinson-hyperlegible-next-*.woff2` — Atkinson Hyperlegible Next (Braille Institute): body text and figures.
