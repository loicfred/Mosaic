Data

Olist Brazilian e-commerce marketplace, January 2017 to August 2018. Amounts are gross item sales in Brazilian reais (BRL): not profit, not cash, and not Mauritian data. Dollar figures (≈ USD) use an equal-month average of 3.33 reais per dollar over that period, for scale only (Federal Reserve monthly rates).

Every number comes from the Mosaic analytics API; this site only formats it.
